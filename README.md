# Mothership Star Map

An interactive star map for our Mothership RPG campaign, hosted on GitHub Pages:
https://ctompkinson.github.io/mothership-star-map/

Drag to pan, scroll or pinch to zoom, and click a location to see its details and jump routes.

`index.html` is generated from an Obsidian canvas. Don't edit it here; rebuild and publish it from the vault with `Star Map Site/publish.sh`.
